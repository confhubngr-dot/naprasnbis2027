# NAPRAS 2027

Registration and delegate passes for the 32nd NAPRAS and 20th NBIS AGM.

**Live at:** https://napras2027.confhub.ng

## Files
- `register.html` — public registration form
- `pass.html` — delegate pass (QR code)

## Editing
Only one line ever changes: `API_URL` at the top of `register.html`.
`pass.html` needs nothing.

Event name, dates, categories, prices, bank details and Paystack link all
live in the private Google Sheet — not in this repo.

## Private sheet
"NAPRAS 2027 — Registration (PRIVATE)" on confhub.ngr@gmail.com
Holds delegate emails and phone numbers. Never make it public.
